Anomaly scoring playground

A big percentage change is not always unusual. Compare each event with its service’s normal variability. These examples use the corrected Pyroscope score: a noisy baseline reduces the score, while a stable baseline makes deviations stand out.

How the score works

Baseline = median of the 12 preceding samples.
MAD = median absolute distance from that baseline.
scale = max(1.4826 × MAD, 1% × |baseline|, 1)
score = |peak − baseline| / scale
change = |peak − baseline| / max(|baseline|, 1% × |baseline|, 1)

The 1% / 1-unit floor prevents division by zero or enormous scores for perfectly flat baselines. Scores are not probabilities or a measure of business impact. Units matter near zero.

Blue = sample values; dashed yellow = baseline; shaded region = example event. Thresholds are applied to the first event sample; the reported score uses the event’s peak and the same pre-event scale.

This is a scoring explainer, not a full detector port. Each example has a fixed baseline and event window. Production detection also handles gaps, flatness filtering, recovery, confirmation, and event segmentation. Duration and absolute impact should be considered separately from score.
