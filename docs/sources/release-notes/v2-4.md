## Version 2.4.0 release notes

Grafana Pyroscope 2.4.0 adds experimental deterministic profile IDs, an optional distributor inflight bytes limit, and improvements to profile replay and asynchronous queries. It also improves compaction efficiency and includes security and stability fixes.

Notable changes are listed below. For the full diff, see the [2.4.0 changelog](https://github.com/grafana/pyroscope/compare/v2.3.0...v2.4.0).

### Enhancements

* **distributor**: Add an optional instance-level inflight bytes limit ([#5546](https://github.com/grafana/pyroscope/pull/5546))
* **experimental**: Add opt-in deterministic profile ID generation ([#4762](https://github.com/grafana/pyroscope/pull/4762))
* **experimental**: Support dedicated storage for asynchronous queries ([#5756](https://github.com/grafana/pyroscope/pull/5756))
* **experimental**: Add queries to confirm externally detected profile anomalies ([#5686](https://github.com/grafana/pyroscope/pull/5686))
* **otlp**: Detect profile language from `telemetry.sdk.language` ([#5606](https://github.com/grafana/pyroscope/pull/5606))
* **profilecli**: Add timestamp-ordered dumps and streaming replay ([#5762](https://github.com/grafana/pyroscope/pull/5762))
* **profilecli**: Add optional replay dump anonymization ([#5763](https://github.com/grafana/pyroscope/pull/5763))
* **symdb**: Optimize insertion into wide stacktrace trees ([#5732](https://github.com/grafana/pyroscope/pull/5732))
* **symdb**: Reduce compaction memory held by source symbols ([#5734](https://github.com/grafana/pyroscope/pull/5734))
* **query-backend**: Optimize label-name queries ([#5556](https://github.com/grafana/pyroscope/pull/5556))
* **segment-writer**: Measure ingestion bytes without re-serializing profiles ([#5312](https://github.com/grafana/pyroscope/pull/5312))
* **Helm**: Support per-component extra labels on pod templates ([#5752](https://github.com/grafana/pyroscope/pull/5752))

### Fixes

* Revert the experimental symbol-reference tree query path ([#5629](https://github.com/grafana/pyroscope/pull/5629))
* **metastore**: Reconcile Raft log writes that complete after a timeout ([#5307](https://github.com/grafana/pyroscope/pull/5307))
* **metastore**: Fix a compaction queue statistics leak during restore ([#5676](https://github.com/grafana/pyroscope/pull/5676))
* Clean up stale ring members on shutdown and through auto-forget ([#5434](https://github.com/grafana/pyroscope/pull/5434))
* **query-backend**: Avoid retrying responses gRPC cannot deliver ([#5590](https://github.com/grafana/pyroscope/pull/5590))
* **query-frontend**: Handle empty asynchronous results ([#5677](https://github.com/grafana/pyroscope/pull/5677))
* **query-frontend**: Tolerate concurrent asynchronous-artifact cleanup ([#5679](https://github.com/grafana/pyroscope/pull/5679))
* **symdb**: Handle line-less locations in Go PGO profiles ([#5635](https://github.com/grafana/pyroscope/pull/5635), [#5636](https://github.com/grafana/pyroscope/pull/5636))

* Validate UTF-8 before truncating symbols at rune boundaries ([#5692](https://github.com/grafana/pyroscope/pull/5692), [#5696](https://github.com/grafana/pyroscope/pull/5696))
* Fix source lookup for installed Python packages ([#5730](https://github.com/grafana/pyroscope/pull/5730))

* **profilecli**: Avoid closing replay datasets twice ([#5591](https://github.com/grafana/pyroscope/pull/5591))

### Security fixes

* Update the Go toolchain to 1.26.9 ([#5788](https://github.com/grafana/pyroscope/pull/5788)).
* Update `golang.org/x/net` to v0.60.0, addressing CVE-2026-78659 and CVE-2026-78660 ([#5791](https://github.com/grafana/pyroscope/pull/5791)).
* Update UI `source-map-js` to v1.2.2, addressing CVE-2026-93749 ([#5795](https://github.com/grafana/pyroscope/pull/5795)).

This release also includes the security updates delivered in [2.3.1 and 2.3.2](https://grafana.com/docs/pyroscope/latest/release-notes/v2-3/).
